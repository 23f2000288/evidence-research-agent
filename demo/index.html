Design decision

Verify evidence before polishing prose.

Each claim must supply a source ID and an exact passage. The program builds citations from that record, rather than asking a model to invent links.

A second model call checks whether the evidence actually supports the interpretation. Source decisions remain visible even for rejected documents.

One important limitation

A real quotation can still be misinterpreted.

The reviewer uses the same model family and may share its blind spots. Exact matching proves the passage exists; it does not prove the conclusion.

The agent also trusts the supplied metadata. It cannot authenticate filings or judge valuation without additional data.

Research aid for a fictional test company. No live-data bonus was attempted. A person should review source support before relying on a brief.
